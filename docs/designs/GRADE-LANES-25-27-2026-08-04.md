## 2. THE INSTRUMENT, AND ITS RED-PROOF

Mutations were applied by **wrapper-free replication**: read the module's own
source from disk, apply a textual mutation whose anchor occurrence count is
**asserted** before replacement, then
`exec(compile(mutated, m.__file__, "exec"), m.__dict__)` and run pytest in the
same process. Nothing on disk changes; the test files are never edited.

The anchor-count assert exists because the dangerous failure direction here is a
mutation that silently fails to apply and reads as "no test caught it" — a
**fabricated hole**. Two control modes prove the instrument:

`[MEASURED HERE]` A canary that only rebound a module constant would not have
proved this; the canary was deliberately placed in a **method body** because the
class object is rebuilt by the exec and the tests must pick up the new one.
