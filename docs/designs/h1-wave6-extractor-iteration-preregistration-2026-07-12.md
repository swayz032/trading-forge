## §8 — READ-ORDER PIN + PASS-2 PRE-COMMITMENT (frozen 2026-07-13, BEFORE the aggregate coverage number exists)

**§8a — READ-ORDER: COVERAGE (Gate 2) is read BEFORE SUPPORT (Gate 3).** A support-rate win is UNINTERPRETABLE without its coverage context — because the cheapest way to "quote faithfully" is to STOP EXTRACTING THE HARD PARTS. Gate 2 is what makes Gate 3 mean something: only a support improvement that held coverage ≥90% is a real improvement; a support number bought by dropping unquotable conditions is omission wearing a good score. So the relay reads coverage first, support second, always.

**§8b — PASS-2 PRE-COMMITMENT: the NO-QUOTE SENTINEL (written now, before the coverage aggregate is known).** Quote-first corners the model on an unquotable condition into a FALSE binary: fabricate a quote (caught by the mechanical substring check) OR drop the condition (caught by the coverage gate). Both are infidelities. The honest THIRD DOOR is a **no-quote sentinel**: the schema permits a condition emitted with an explicit empty/`null` `transcript_quote` marker — which **routes UNANCHORED, counts against support truthfully, but PRESERVES coverage.** The model should NEVER face a choice between inventing evidence and silencing the trader; **"I extracted this condition but cannot ground it in a verbatim quote" is a legitimate, honest output the pipeline already punishes fairly** (UNANCHORED → not certificate-grade, exactly as it should be). ROUTING (pre-committed, conditional on Gate 2's outcome, decided before the number): **if aggregate coverage ≥ 90% → Gate 2 HOLDS, pass-1's coverage is faithful, and the sentinel stays a REGISTERED DESIGN NOTE (not built this pass).** **If aggregate coverage < 90% → Gate 2 FAILS, pass-1 fails honestly (the omission fence doing exactly its job), and the no-quote sentinel IS the pre-positioned PASS-2 shape** — the second of the ≤2-pass budget, aimed at the named mechanism (the fabricate-or-drop corner), not improvised after the fail. Either way, pass-1's verdict on Gate 2 stands as written; the sentinel does not retroactively rescue a pass-1 coverage miss.
