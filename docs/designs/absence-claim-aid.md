# Absence-claim aid (R-316 §3)

**This is an AID, not a guard.** It never blocks anything and it never votes on a
verdict. It exists because both desks repeated a taught law *within one ruling of
being taught it* — which is evidence that "a claimed absence owes its search" is
unenforceable as memory and needs a prompt attached to the moment of writing.

## The law it prompts for

> A claimed absence is a CLAIM. "Nothing detects this", "there is no test",
> "previously unguarded", "the only place" — each asserts that a search was run
> and came back empty. **Publish the search, or do not publish the absence.**

## The pattern set — derived from the FORMS the claim takes

Derived from the forms, not collected from remembered phrasings, so it catches
constructions nobody has written yet.

| Family | Forms |
|---|---|
| **Non-existence** | `does not exist`, `no such`, `is absent`, `never existed`, `not present`, `missing` |
| **No-detector** | `nothing detects`, `nothing catches`, `nothing checks`, `nothing prevents`, `caught by nothing`, `no guard`, `unguarded`, `ungated` |
| **No-coverage** | `no test`, `not covered`, `untested`, `no CI`, `never exercised`, `zero callers`, `no callers` |
| **Uniqueness** | `the only`, `only place`, `sole`, `nowhere else`, `no other` |
| **Temporal** | `previously <X>`, `used to be`, `no longer`, `never checked`, `has never` |
| **Quantified zero** | `zero <noun>`, `none of`, `not one`, `0 of` |

## How to use it

Before a report leaves either desk, scan it for these forms. For each hit ask one
question:

> **Did I run the search that would have falsified this — and is that search in
> the report?**

Three legitimate outcomes. Only the third is a defect:

1. **Search run and reported** — cite it (`grep`, the census, the file listing).
2. **Search not run** — downgrade the wording: *"I did not find"* ≠ *"there is
   none"*. Say which.
3. **Search not run, absence asserted anyway** — fix before sending.

## Why it is deliberately not a guard

An aid that never bites is an aid. Wiring this as a blocking check would make it
a guard with a hostile-input problem: absence claims are prose, the pattern set
will never be complete, and a *partial* guard reporting green would assert its
own false absence — the exact defect it exists to catch. It stays an aid on
purpose.

## Provenance

Minted R-316 §3, after the working desk wrote "previously unguarded" one ruling
after being taught the law (a sibling suite already guarded that direction), and
the advisory desk issued three mechanism-shaped orders in the same arc.
