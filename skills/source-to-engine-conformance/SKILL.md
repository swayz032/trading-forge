# Source-to-Engine Conformance

## Freeze the proof object

V1.0 uses `st5e-YJRfKc__s0 / opening_range_breakout`. Record exact artifact identities and provenance at every edge. A hand-built binding, substitute specimen, TS/Python comparison, profitable backtest, or green fixture cannot prove this real path.

Reconcile this lineage without gaps:

`source lesson -> extracted evidence -> sealed strategy specification -> canonical typed conditions -> production bindings -> production evaluator decisions -> independent bar-by-bar reference`

If an artifact is missing, stale, or inaccessible, return `REFUSE`; do not infer its contents.

## Reconcile complete meaning

Enumerate and compare every taught:

- condition and parameter;
- sequence and event-order constraint;
- market, portability scope, session, timezone, range start/duration, and high/low construction;
- breakout, direction, entry timing, expiration, and invalidation;
- source-defined stop, target, and numeric value.

Missing, duplicate, reordered, silently defaulted, unknown, approximated, dropped, or neighboring concepts deny conformance unless the source explicitly authorizes them. Keep source-defined stop, target, and invalidation separate from framework-owned overlays; neither may substitute for the other.

Map every required condition to a production evaluator or a named framework-owned component. A component name without an executed decision path is insufficient.

## Prove behavior independently

Build deterministic bars and an independent reference whose expected behavior is not derived from the implementation under test. Compare decisions bar by bar, including entries, exits, stops, targets, and event order.

Require an unmutated GREEN control plus RED-before/GREEN-after evidence. Mutate, one at a time:

- opening-range duration;
- session time;
- breakout trigger;
- direction;
- stop;
- target;
- condition ordering;
- one required parameter.

Prove each mutation was applied and failed for its intended reason. A mutation caught accidentally by another check is not evidence for the named guarantee.

## Rule narrowly

Return exactly `PASS`, `FAIL`, or `REFUSE`. Missing source meaning is a measured refusal, never permission to invent a default. Negative P&L does not deny conformance; edge qualification follows this proof.

The receipt must identify frozen objects, edge provenance, membership reconciliation, evaluator coverage, reference independence, bar-by-bar results, mutation attribution, source-versus-framework separation, residual uncertainty, and the verdict.

Remember:

- TS/Python agreement proves parity only.
- Profitable output proves no source fidelity.
- A green fixture proves only that fixture.
