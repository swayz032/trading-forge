# 6. ROBUST ENGINEERING STANDARD FOR EVERY GPT LANE

Every GPT work order/ruling should satisfy these laws.

## R1 — Measure before design

Inspect the actual repo path first. Never assume a missing capability when it may already exist.

## R2 — Reuse before rebuild

Prefer the existing semantic/runtime authority. No duplicate scheduler, lifecycle service, context brain, hash authority, or audit spine without proof the current one cannot satisfy the contract.

## R3 — One semantic authority

Do not create two independent implementations that can disagree about:

- source stop geometry;
- timeframe roles;
- strategy identity;
- feed identity;
- promotion state;
- reserve eligibility;
- context feature semantics.

## R4 — Fail closed on ambiguity

Unsupported/ambiguous source meaning, unresolved feed identity, ambiguous assignment state, missing receipt evidence, or runtime mismatch must not become a silent success.

## R5 — RED -> GREEN evidence

Every repair needs a pre-fix failing witness and post-fix green witness on the production path when practical.

## R6 — Positive controls + mutation controls

A green test is weak unless the protected behavior can be made to fail by a relevant mutation/ablation.

## R7 — Test the real seam

Do not test a copied helper while production code remains unexercised.

## R8 — Provenance is immutable

Machine output/report tables should derive from machine artifacts. Do not hand-clean labels/rows in ways that create a second drifting truth.

## R9 — Idempotency / restart safety

Anything scheduled, resumable, or state-changing must define duplicate/retry/restart behavior explicitly.

## R10 — No false green

Unknown, partial, stale, or missing evidence is not GREEN. Define YELLOW/RED separately.

## R11 — Smallest vertical slice

Repair the first measured broken join end-to-end before expanding sideways.

## R12 — Protect Claude quota

If GPT can pre-trace a call graph, reuse decision, test plan, schema, acceptance contract, or branch integration problem without colliding with AR-1138, GPT should do it before asking Claude to rediscover it.
