# Vertical Slice Breakthrough

Prove one causal path before broadening the investigation.

## Structural trace

Create one trace with these stages:

1. **source words** — Freeze the real artifact; quote only its relevant words.
2. **extraction record** — Capture the emitted record and provenance on the same path.
3. **canonical typed meaning** — Compare the record with the required typed representation.
4. **binding attempt/refusal** — Show the binding input and its accepted, rejected, or absent result.
5. **exact engine capability** — Verify the concrete consumer capability and contract.
6. **first failed handoff** — Name the earliest measured divergence and its evidence.

Run a same-path control beside the frozen real artifact. Repair only the first measured broken handoff. Require RED before the repair, GREEN after it, and an independent negative control. Never invent a value, result, provenance, or capability.

Admit adjacent tooling only when it blocks this trace or invalidates its evidence or receipt. Give every other finding a stable ID and defer it. Stop broadening once the divergence is identified. Repeat the proven method condition-by-condition only after the first condition binds.

Fan out independent read-only traces only when they share no mutable resource. Widen scope only when corpus-wide evidence invalidation is real and recorded.

## Required output

```text
ARTIFACT / CONTROL:
TRACE: six stages with evidence locations
FIRST FAILED HANDOFF:
RED / GREEN / NEGATIVE CONTROL:
REPAIR:
DEFERRED: ID — finding
SCOPE / UNCERTAINTY:
```

## Red flags

- Auditing a neighboring guard before locating the first divergence.
- Repairing a later symptom or several boundaries together.
- Calling an unmeasured engine capability present.
- Treating a control on another path as comparable.

## Rationalizations

| Rationalization | Counter |
|---|---|
| "The audit may reveal the cause." | Trace the frozen artifact first. |
| "Fix all obvious defects together." | Repair the earliest measured handoff only. |
| "The control is close enough." | Require the same path and an independent negative control. |
