## Universal GPT grade rule
Worker prose is an index, not proof.

Grade order:
1. resolve exact commit/branch;
2. inspect diff and actual production path;
3. inspect tests and whether they execute real code;
4. inspect RED/GREEN/negative/mutation evidence;
5. check cross-lane/forbidden changes;
6. issue ACCEPT / CORRECT / STOP with exact SHA and next bounded order.

No PASS from screenshots, summaries, test counts, or report language alone.
